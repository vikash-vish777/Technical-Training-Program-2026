BIG O :- it is a complexity that is going to be less or equal to the worst case.
BIG-OMEGA :- it is a complexity that is going to be least more than the best case.
BIG-THETA :- it is a complexity that is within bounds of the worst and the best cases.

O(1) :- CONSTANT TIME

ex:
  arr=[1,8,2,10,4]
  arr[0] // it take constant time to access first element


O(N) :- LINEAR TIME
ex:
    arr=[1,8,2,10,4]
    for element in arr:
        print(element) //linear time since it is visiting every element of array

O(LogN) :- LOGARITHMIC TIME
ex:

  arr=[1,8,2,10,4]
  for index in range(0,len(arr),3):
    print(arr[index]) //logarithmic time since it is visiting only some element 


O(N2) :- QUADRATIC TIME 
Ex:
  arr=[1,8,2,10,4]
  for x in arr:
    for y in arr:
      print(x,y)// looking for a every index in the array twice



o(2n) :- EXPONENTIAL TIME

Ex:
  def fibonacci(n):
    if n<=1:
      return N
    return fibonacci(n-1)+fibonacci(n-2)
